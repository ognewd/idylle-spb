# 📄 План создания системы управления страницами (CMS)

## Статус проекта
✅ Создана модель Page в Prisma
✅ Созданы API endpoints для управления страницами
🚧 Создается админ-панель
⏳ Drag and drop функционал
⏳ Обновление существующих страниц
⏳ Создание недостающих страниц
⏳ Тесты

## Реализовано

1. **Модель Page** в Prisma schema:
   - slug (уникальный)
   - title
   - content (HTML)
   - metaTitle, metaDescription (SEO)
   - isActive, sortOrder
   - timestamps

2. **API endpoints**:
   - `GET /api/admin/pages` - список всех страниц
   - `POST /api/admin/pages` - создание страницы
   - `GET /api/admin/pages/[id]` - получение страницы
   - `PUT /api/admin/pages/[id]` - обновление страницы
   - `DELETE /api/admin/pages/[id]` - удаление страницы
   - `GET /api/pages/[slug]` - публичный API для получения страницы

## В процессе

3. **Админ-панель** (`/admin/pages`):
   - Список всех страниц
   - Создание/редактирование/удаление
   - Редактор контента (react-quill, как в категориях)
   - Предпросмотр
   - SEO поля (meta title, description)

## Следующие шаги

   - Поддержка JSON структуры контента
   - Блоки: текст, заголовок, изображение, список и т.д.

5. **Обновление существующих страниц**:
