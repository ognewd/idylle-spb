# Документы на товар

## Как добавить документы

1. Зайдите в **админку** → **Товары** → откройте нужный товар (**Редактировать**).
2. Прокрутите до блока **«Документы на товар»** (карточка с иконкой документа).
3. Заполните:
   - **Тип документа** — выберите: «Сертификат гос. регистрации», «Декларация соответствия», «Отказное письмо» или «Прочее».
   - **Название** — как будет отображаться на сайте (например: «Декларация ЕАЭС»). Если не указать, подставится имя файла.
   - **Файл** — прикрепите файл (PDF, JPG, PNG, WEBP, DOC, DOCX).
4. Нажмите **«Добавить документ»** (или выберите файл — загрузка начнётся сразу).
5. При необходимости добавьте ещё документы. Удалить можно кнопкой с крестиком рядом с названием.

Документы сохраняются на сервере в `uploads/documents/` и привязываются к товару.

---

## Где отображаются

- **На сайте:** на **странице товара** в каталоге (`/catalog/[slug]`), в колонке справа под блоком с ценой и описанием.
- Блок называется **«Документы на товар»**, подпись: «Сертификаты, декларации и отказные письма для вашего спокойствия».
- Каждый документ — ссылка (открывается в новой вкладке). Рядом с названием выводится тип (например, «Сертификат гос. регистрации»), кроме типа «Прочее».

Если у товара нет ни одного документа, блок на странице товара не показывается.
