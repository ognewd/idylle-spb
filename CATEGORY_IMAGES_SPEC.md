# 📸 Спецификация изображений для категорий

**Последнее обновление:** 2026-01-10

---

## 🎯 Назначение изображений категорий

Изображения категорий используются в следующих местах:

1. **Hero Banner** - главное изображение вверху страницы категории (header)
2. **Карточки категорий** - на главной странице и в каталоге
3. **Миниатюры** - в фильтрах и навигации

---

## 📏 Размеры изображений

### 1. Hero Banner (Header категории)

**Назначение:** Главное изображение вверху страницы категории  
**Использование:** Фон hero-секции на странице категории

**Рекомендуемые размеры:**
- **Ширина:** `1920px` (Full HD)
- **Высота:** `500px - 800px`
- **Соотношение сторон:** `16:9` или `21:9` (широкое)
- **Минимальная ширина:** `1200px`
- **Максимальная ширина:** `2560px` (для Retina дисплеев)

**Оптимизация:**
- Для мобильных: `1200x500px` (3:5 ratio)
- Для десктопа: `1920x800px` (12:5 ratio)

**Пример использования:**
```tsx
// Как в /brands/page.tsx
<div 
  className="absolute inset-0 bg-cover bg-center"
  style={{
    backgroundImage: 'url(/uploads/categories/category-slug-hero.jpg)',
  }}
>
```

---

### 2. Карточки категорий (Главная страница)

**Назначение:** Изображение категории в карточке на главной странице  
**Использование:** Карточки категорий в секции "Популярные категории"

**Рекомендуемые размеры:**
- **Ширина:** `800px`
- **Высота:** `600px`
- **Соотношение сторон:** `4:3` (стандарт)
- **Минимальная ширина:** `600px`
- **Максимальная ширина:** `1200px` (для Retina)

**Текущее отображение:** `aspect-[4/3]` (строка 205 в `/page.tsx`)

---

### 3. Миниатюры категорий

**Назначение:** Маленькие изображения в фильтрах, навигации, иконки  
**Использование:** Фильтры, боковая навигация

**Рекомендуемые размеры:**
- **Ширина:** `200px - 400px`
- **Высота:** `200px - 400px`
- **Соотношение сторон:** `1:1` (квадрат)
- **Оптимально:** `300x300px`

---

## 🖼️ Формат файлов

### Рекомендуемый формат: **WebP** (приоритет) или **JPG**

**WebP:**
- ✅ Лучшее сжатие (на 25-35% меньше размер)
- ✅ Поддержка прозрачности
- ✅ Поддержка всеми современными браузерами
- ✅ Поддержка Next.js Image Optimization

**JPG:**
- ✅ Универсальная совместимость
- ✅ Хорошее качество
- ✅ Меньший размер чем PNG

**PNG:**
- ⚠️ Только если нужна прозрачность (для миниатюр с логотипами)

## 📊 Технические характеристики

### Качество изображения:
- **Hero Banner:** 80-85% (баланс качество/размер)
- **Карточки:** 85-90%
- **Миниатюры:** 75-80%

### Оптимизация:
- **Максимальный размер файла:**
  - Hero Banner: `200-300 KB`
  - Карточки: `100-150 KB`
  - Миниатюры: `20-50 KB`

### Цветовое пространство:
- **sRGB** (стандарт для веб)

## 🎨 Стилистические требования

### Hero Banner (Header):

**Контент изображения:**
- ✅ Репрезентативные изображения товаров категории
- ✅ Высококачественные фото продуктов
- ✅ Красивые композиции
- ✅ Профессиональная фотография

**Дизайн:**
- ✅ Достаточно "воздуха" для текста поверх изображения
- ✅ Темные участки для светлого текста (или наоборот)
- ✅ Использование overlay для читаемости текста

**Пример стиля:**
- Ароматы для дома: интерьер, диффузоры, свечи
- Парфюмы: бутылочки духов, композиции
- Аксессуары: предметы декора, подарочные наборы

### Карточки категорий:

**Контент:**
- ✅ Яркие, привлекательные изображения
- ✅ Фокус на товарах категории
- ✅ Четкий визуальный акцент

### Миниатюры:

**Контент:**
- ✅ Узнаваемые элементы категории
- ✅ Логотипы или иконки
- ✅ Простые композиции

## 💻 Интеграция в код

### Текущая структура БД:

В `prisma/schema.prisma` есть поле:
```prisma
model Category {
  image String?  // URL изображения категории
  // ...
}
```

### Рекомендуемое расширение:

Можно добавить несколько полей для разных типов изображений:

```prisma
model Category {
  image          String?  // Основное изображение (hero)
  cardImage      String?  // Изображение для карточек
  thumbnailImage String?  // Миниатюра
  // ...
}
```

### Использование в компонентах:

**Hero Banner:**
```tsx
<div 
  className="absolute inset-0 bg-cover bg-center"
  style={{
    backgroundImage: category.image 
      ? `url(${getImageUrl(category.image)})` 
      : 'linear-gradient(to right, #1e293b, #0f172a)',
  }}
>
  <div className="absolute inset-0 bg-gradient-to-r from-black/75 via-black/60 to-black/40"></div>
</div>
```

**Карточки:**
```tsx
<Image
  src={category.cardImage || category.image || '/placeholder-category.jpg'}
  alt={category.name}
  width={800}
  height={600}
  className="object-cover"
/>
```

## 🔧 Инструменты для подготовки

### Оптимизация изображений:

1. **Online:**
   - [Squoosh](https://squoosh.app/) - конвертация в WebP
   - [TinyPNG](https://tinypng.com/) - сжатие PNG/JPG

2. **Desktop:**
   - [ImageOptim](https://imageoptim.com/) (macOS)
   - [GIMP](https://www.gimp.org/) - редактирование
   - [Photoshop](https://www.adobe.com/products/photoshop.html)

3. **CLI:**
   ```bash
   # Установка cwebp (WebP encoder)
   brew install webp  # macOS
   
   # Конвертация в WebP
   cwebp -q 85 input.jpg -o output.webp
   
   # Сжатие
   cwebp -q 80 -resize 1920 800 input.jpg -o hero.webp
   ```

## 📱 Responsive изображения

### Использование Next.js Image:

```tsx
import Image from 'next/image';

<Image
  src={category.image}
  alt={category.name}
  width={1920}
  height={800}
  className="w-full h-full object-cover"
  sizes="100vw"
  priority
/>
```

Next.js автоматически:
- ✅ Генерирует разные размеры
- ✅ Оптимизирует для разных устройств
- ✅ Использует WebP когда поддерживается
- ✅ Ленивую загрузку для не-приоритетных изображений

## 🎯 Примеры для разных категорий

### 1. Парфюмы (Perfume)
- **Hero:** Бутылочки духов на темном фоне, красивая композиция
- **Карточка:** Коллекция духов, яркие цвета
- **Миниатюра:** Иконка бутылочки или логотип

### 2. Товары для дома (Home)
- **Hero:** Интерьер с диффузорами и свечами, уютная атмосфера
- **Карточка:** Композиция товаров для дома
- **Миниатюра:** Иконка дома

### 3. Аксессуары (Accessories)
- **Hero:** Подарочные наборы, декоративные предметы
- **Карточка:** Яркие аксессуары
- **Миниатюра:** Иконка подарка
