# 🔍 Как проверить, что Git подключен к Vercel

## ✅ Способы проверки

### 1. Через Vercel Dashboard (самый надежный)

1. **Откройте:**
   https://vercel.com/dashboard/project/idylle-spb/settings/git

2. **Должно быть показано:**
   - ✅ **Connected Git Repository:** `ognewd/idylle-spb`
   - ✅ **Production Branch:** `main`
   - ✅ **Auto-deploy:** Enabled (или показано, что включено)

3. **Если подключено:**
   - Вы увидите название репозитория
   - Кнопку "Disconnect" (если нужно отключить)
   - Настройки деплоя

---

### 2. Проверить последние деплои

1. **Откройте:**
   https://vercel.com/dashboard/project/idylle-spb

2. **Перейдите в "Deployments"**

3. **Проверьте последний деплой:**
   - Если подключение успешно, должен появиться **новый деплой** автоматически
   - В "Source" должно быть указано: `main` (branch) и commit hash

4. **Если видите деплой с источником `main`** → подключение работает ✅

---

### 3. Тестовый push (самый простой способ)

1. **Сделайте небольшое изменение:**
   ```bash
   echo "# Test" >> TEST.md
   git add TEST.md
   git commit -m "test: проверка автоматического деплоя"
   git push origin main
   ```

2. **Следите за Vercel:**
   - Откройте: https://vercel.com/dashboard/project/idylle-spb
   - Должен появиться **новый деплой** в течение 30 секунд
   - Статус: "Building..." → "Ready"

3. **Если деплой запустился автоматически** → подключение работает ✅

---

### 4. Проверить через Vercel CLI

```bash
vercel ls
```

Посмотрите последние деплои - если есть деплой с источником из Git (а не через CLI), значит подключение работает.

---

## ❌ Если подключение НЕ работает

**Признаки:**
- В Settings → Git ничего не показано
- Деплои запускаются только через `vercel --prod`
- Push в Git не триггерит деплой

**Решение:**
1. Вернитесь в Settings → Git
2. Проверьте, что репозиторий подключен
3. Если нет - подключите заново

---

## ✅ Ожидаемый результат после подключения

- ✅ Репозиторий `ognewd/idylle-spb` отображается в Settings → Git
- ✅ Production Branch: `main` настроен
- ✅ Каждый `git push origin main` автоматически деплоит проект
- ✅ В Deployments видны деплои с источником `main` (branch)
