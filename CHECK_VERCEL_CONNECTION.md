## 🔧 Как проверить подключение вручную

### Вариант 1: Через Vercel Dashboard

1. Откройте https://vercel.com/dashboard
2. Войдите через GitHub
3. Проверьте, есть ли проект `idylle-spb`
4. Если есть - проект подключен
5. Если нет - нужно создать проект

### Вариант 2: Через Vercel CLI

```bash
# Установить Vercel CLI (если не установлен)
npm i -g vercel

# Войти в Vercel
vercel login

# Проверить текущий проект
vercel ls

# Или связать проект
vercel link
```

### Вариант 3: Проверить через Git

Vercel автоматически подключается к GitHub репозиториям. Если:
- ✅ Репозиторий есть на GitHub: `https://github.com/ognewd/idylle-spb.git`
- ✅ Проект создан в Vercel Dashboard
- ✅ Репозиторий подключен к проекту

То каждый `git push` будет автоматически запускать деплой.
