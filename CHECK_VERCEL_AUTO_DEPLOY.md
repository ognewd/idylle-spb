## ✅ Как проверить автоматический деплой

### Вариант 1: Vercel Dashboard

1. Откройте: https://vercel.com/dashboard
2. Найдите проект `idylle-spb`
3. Перейдите в **Settings** → **Git**
4. Проверьте:
   - **Connected Git Repository:** должен быть `ognewd/idylle-spb`
   - **Production Branch:** должен быть `main`
   - **Auto-deploy:** должен быть включен ✅

### Вариант 2: Проверить деплойменты

1. Vercel Dashboard → Проект → **Deployments**
2. Проверьте, есть ли новый деплой после вашего push
3. Если нет - автоматический деплой не настроен

---

## 🚀 Запустить деплой вручную

Если автоматический деплой не настроен, запустите вручную:

```bash
vercel --prod
```

Или через Vercel Dashboard:
1. Проект → **Deployments** → **Create Deployment**
2. Выберите branch `main`
3. Нажмите **Deploy**

---

## 🔧 Настроить автоматический деплой

Если автоматический деплой не настроен:

1. Vercel Dashboard → Проект → **Settings** → **Git**
2. Нажмите **Connect Git Repository**
3. Выберите `ognewd/idylle-spb`
4. Настройте:
   - **Production Branch:** `main`
   - **Auto-deploy:** ✅ включить
5. Нажмите **Save**

После этого каждый push в `main` будет автоматически деплоить.
