# Клонирование прода в dev (схема БД + все данные, включая товары)

Чтобы локально получить полную копию базы с прода (товары, заказы, пользователи, категории и т.д.):

## Шаг 1: Получить дамп с прода

### Вариант А: с сервера по SSH

```bash
# Подключись к серверу
ssh root@147.45.98.110

# В каталоге проекта
cd /root/idylle-spb

# Загрузи переменные из .env (там DATABASE_URL прода)
set -a && source .env && set +a

# Создай дамп (без владельцев объектов — так проще восстанавливать локально)
pg_dump "$DATABASE_URL" --no-owner --no-acl -F p -f prod_dump.sql

# Выйди с сервера
exit

# Скачай файл к себе в проект
scp root@147.45.98.110:/root/idylle-spb/prod_dump.sql .
```

### Вариант Б: с твоей машины, если есть доступ к БД прода

Если с твоего компьютера открыт доступ к PostgreSQL на проде (тоннель или белый IP):

```bash
# Один раз задай URL прода (не коммитить в репозиторий!)
export PROD_DATABASE_URL="postgresql://idylle_user:ПАРОЛЬ@147.45.98.110:5432/idylle_spb?schema=public"

./scripts/dump-prod.sh prod_dump.sql
```

## Шаг 2: Восстановить дамп в локальную dev-базу

Убедись, что в `.env.local` указана локальная БД:

```env
DATABASE_URL="postgresql://dognev@localhost:5432/idylle_spb_dev"
```

Выполни:

```bash
./scripts/clone-prod-to-dev.sh prod_dump.sql
```

Скрипт пересоздаст базу `idylle_spb_dev` и заполнит её из дампа. После этого в dev будут те же схема и данные, что на проде.

## Шаг 3: Запуск приложения

```bash
npm run dev
```

Логин в админку — как на проде (или admin@idylle.spb.ru / admin123, если такой пользователь есть в дампе).

## Шаг 3.5: Показ изображений товаров в dev

В дампе пути к картинкам ведут на `/uploads/...`, но файлов локально нет. Два варианта:

**Вариант А (рекомендуется):** грузить картинки с прода. В `.env.local` добавьте:

```env
NEXT_PUBLIC_IMAGE_BASE_URL=https://aromarussia.ru
```

После перезапуска `npm run dev` изображения товаров будут подгружаться с продакшена.

**Вариант Б:** скопировать папку загрузок с сервера (см. шаг 4).

## Шаг 4 (по желанию): Скопировать картинки с прода

В дампе только БД; пути к картинкам в БД есть, но сами файлы локально отсутствуют. Чтобы товары отображались с фото, подтяни папку загрузок с сервера:

```bash
./scripts/sync-uploads-from-prod.sh
```

Потребуется пароль от `root@147.45.98.110`. Скрипт скопирует содержимое `/var/www/uploads/` в `public/uploads/`.
