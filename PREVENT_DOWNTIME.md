# Предотвращение простоев сайта

## Что произошло?

Сайт упал из-за отсутствия собранного приложения (`.next/BUILD_ID`). PM2 пытался запустить Next.js, но падал, так как билд не был создан.

## Причины

1. **Отсутствие сборки после обновления кода** - после `git pull` не был выполнен `npm run build`
2. **Удаление директории `.next`** - случайное или намеренное удаление
3. **Сбой GitHub Actions** - workflow мог упасть до завершения сборки

## Решения

### 1. Автоматический деплой через GitHub Actions ✅

GitHub Actions workflow теперь:
- ✅ Всегда выполняет сборку перед запуском
- ✅ Проверяет наличие `BUILD_ID` после сборки
- ✅ Выполняет проверку здоровья приложения
- ✅ Останавливается при ошибках

**Использование:**
- Просто делайте `git push` в `main` - деплой запустится автоматически
- Или запустите вручную через GitHub Actions UI

### 2. Скрипт полного деплоя ✅

Используйте `scripts/full-deploy.sh` для ручного деплоя:

```bash
cd /root/idylle-spb
./scripts/full-deploy.sh
```

Этот скрипт:
- Обновляет код
- Устанавливает зависимости
- Применяет миграции
- **Собирает приложение**
- Перезапускает PM2
- Проверяет здоровье

### 3. Проверка здоровья ✅

Проверьте состояние приложения в любой момент:

```bash
cd /root/idylle-spb
./scripts/health-check.sh
```

Скрипт проверяет:
- ✅ Наличие `BUILD_ID`
- ✅ Статус PM2
- ✅ Порт 3000
- ✅ HTTP ответ
- ✅ Логи на ошибки

### 4. Автоматическое восстановление ✅

Скрипт `scripts/auto-recover.sh` автоматически:
- Проверяет здоровье
- Восстанавливает билд при необходимости
- Перезапускает PM2 при сбоях

**Настройка cron для автоматической проверки:**

```bash
# Добавьте в crontab (crontab -e):
# Проверка каждые 5 минут
*/5 * * * * /root/idylle-spb/scripts/auto-recover.sh >> /var/log/auto-recover.log 2>&1
```

## Рекомендации

### ✅ Всегда используйте скрипты

**НЕ делайте:**
```bash
git pull
pm2 restart  # ❌ Без сборки!
```

**Делайте:**
```bash
./scripts/full-deploy.sh  # ✅ Полный деплой со сборкой
```

### ✅ Проверяйте после деплоя

После любого деплоя проверьте:
```bash
./scripts/health-check.sh
```

### ✅ Мониторинг логов

Регулярно проверяйте логи:
```bash
pm2 logs idylle-spb --lines 50
```

### ✅ Настройте уведомления

Настройте мониторинг (например, UptimeRobot) для отслеживания доступности сайта.

## Быстрое восстановление

Если сайт упал:

1. **Проверьте проблему:**
   ```bash
   cd /root/idylle-spb
   ./scripts/health-check.sh
   ```

2. **Автоматическое восстановление:**
   ```bash
   ./scripts/auto-recover.sh
   ```

3. **Или полный деплой:**
   ```bash
   ./scripts/full-deploy.sh
   ```

4. **Проверьте результат:**
   ```bash
   pm2 status
   curl http://localhost:3000
   ```

## Контакты для экстренных случаев

Если автоматическое восстановление не помогло:
1. Проверьте логи: `pm2 logs idylle-spb --lines 100`
2. Проверьте базу данных: `psql -U idylle_user -d idylle_spb -c "SELECT 1;"`
3. Проверьте диск: `df -h`
4. Проверьте память: `free -h`
