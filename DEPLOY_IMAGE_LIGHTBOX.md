# Деплой ImageLightbox в продакшен

## Изменения для продакшена

### Новые файлы:
1. **`src/components/product/ImageLightbox.tsx`** - новый компонент для полноэкранного просмотра изображений
   - Упрощенная и надежная реализация
   - Использует React Portal для правильного z-index
   - Блокирует прокрутку и скрывает элементы страницы
   - Поддержка навигации клавиатурой и стрелками

### Измененные файлы:

1. **`src/app/globals.css`**
   - Упрощены CSS правила для `image-lightbox-open`
   - Убраны избыточные селекторы
   - Оставлен только необходимый функционал

2. **`src/components/product/ProductImageCarousel.tsx`**
   - Интеграция с `ImageLightbox`
   - Кнопка "ZoomIn" открывает полноэкранный просмотр

3. **`src/components/product/QuickView.tsx`**
   - Интеграция с `ImageLightbox`
   - Поддержка полноэкранного просмотра из модального окна быстрого просмотра
