Изменения запушены в Git, но не задеплоены автоматически на Vercel.

## ✅ Решение: Настроить автоматический деплой из Git

### Шаг 1: Подключить Git репозиторий к Vercel

1. **Откройте Vercel Dashboard:**
   - https://vercel.com/dashboard/project/idylle-spb

2. **Перейдите в Settings:**
   - Нажмите на проект → **Settings** → **Git**

3. **Проверьте подключение:**
   - Если репозиторий не подключен, нажмите **"Connect Git Repository"**
   - Выберите **GitHub**
   - Авторизуйтесь, если нужно
   - Выберите репозиторий: `ognewd/idylle-spb`

4. **Настройте деплой:**
   - **Production Branch:** `main`
   - **Auto-deploy:** ✅ Включить
   - **Build Command:** (оставить пустым или `npm run build`)
   - **Output Directory:** (оставить пустым для Next.js)
   - **Install Command:** (оставить пустым или `npm install`)

5. **Нажмите "Save"**

---

### Шаг 2: Запустить деплой нового коммита

После подключения Git, Vercel автоматически начнет деплой нового коммита `66f80661`.

Если нужно запустить вручную прямо сейчас:

**Вариант A: Через Vercel Dashboard**
1. Dashboard → Проект → **Deployments**
2. Нажмите **"Redeploy"** на последнем деплое
3. Или нажмите **"Deploy"** → выберите branch `main`

**Вариант B: Через CLI (уже сделано)**
```bash
vercel --prod
```

---

### Шаг 3: Проверить, что деплой работает

После настройки, каждый push в `main` будет автоматически деплоить проект.

**Проверка:**
1. Сделайте небольшое изменение в коде
2. Закоммитьте и запушьте в `main`
3. Vercel должен автоматически начать деплой
