# 🔍 Почему сайт падал - разбор проблемы

## 📋 Что произошло

### 1. **Отсутствовала директория сборки `.next`**

**Ошибка в логах:**
```
Error: ENOENT: no such file or directory, open '/root/idylle-spb/.next/BUILD_ID'
```

**Причина:**
- Next.js требует директорию `.next` со скомпилированными файлами для запуска
- Эта директория создается командой `npm run build`
- Если директории нет, приложение не может запуститься → **502 Bad Gateway**

**Решение:**
```bash
npm run build  # Создает директорию .next
```

---

### 2. **Не были установлены зависимости**

**Ошибка компиляции:**
```
Type error: Cannot find module 'react-quill' or its corresponding type declarations.
```

**Причина:**
- В коде использовался пакет `react-quill`, но он не был установлен на сервере
- В `package.json` был добавлен `react-quill`, но изменения не были закоммичены и запушены вовремя
- После `git pull` на сервере `package.json` обновился, но `npm install` не был выполнен

**Решение:**
```bash
git pull           # Получить обновленный package.json
npm install        # Установить зависимости из package.json
npm run build      # Пересобрать приложение
```

---

### 3. **Проблема с типами TypeScript**

**Ошибка:**
```
Cannot find module 'react-quill' or its corresponding type declarations.
```

**Причина:**
- TypeScript требует типы для модулей
- `@types/react-quill` не существует в npm (или не был установлен)
- TypeScript не мог скомпилировать проект без типов

**Решение:**
```typescript
// @ts-ignore - react-quill не имеет типов в @types
const ReactQuill = dynamic(() => import('react-quill'), { ssr: false });
```

## 🔄 Последовательность событий

1. **Первоначальное состояние:**
   - Сайт работал нормально
   - Приложение было собрано и запущено

2. **Что-то пошло не так:**
   - Возможно, директория `.next` была удалена или повреждена
   - Или после последнего деплоя сборка не была выполнена

3. **Попытка перезапуска:**
   - PM2 попытался перезапустить приложение
   - Но `.next` отсутствовала → приложение не могло запуститься
   - Nginx не мог подключиться к приложению → **502 Bad Gateway**

4. **Попытка собрать приложение:**
   - Выполнили `npm run build`
   - Но обнаружили, что `react-quill` не установлен
   - Компиляция упала с ошибкой

5. **Решение:**
   - Закоммитили и запушили `package.json` с `react-quill`
   - На сервере выполнили `git pull` → обновили `package.json`
   - Выполнили `npm install` → установили зависимости
   - Выполнили `npm run build` → создали `.next`
   - Добавили `@ts-ignore` для импорта `react-quill`
   - Приложение успешно запустилось ✅

## 💡 Как избежать в будущем

### ✅ Правильный порядок деплоя

1. **Локально:**
   ```bash
   # 1. Добавьте новые зависимости
   npm install react-quill
   
   # 2. Закоммитьте ВСЕ изменения (включая package.json)
   git add package.json package-lock.json
   git commit -m "Add react-quill dependency"
   git push
   ```

2. **На сервере:**
   ```bash
   cd /root/idylle-spb
   
   # 1. Получите изменения
   git pull
   
   # 2. Установите зависимости
   npm install
   
   # 3. Примените миграции Prisma (если есть)
   npx prisma db push
   npx prisma generate
   
   # 4. Соберите приложение
   npm run build
   
   # 5. Перезапустите PM2
   pm2 restart idylle-spb
   ```

### ✅ Всегда проверяйте перед деплоем

1. **Локально:**
   - Проверьте, что все зависимости установлены: `npm install`
   - Проверьте, что проект собирается: `npm run build`
   - Проверьте, что проект запускается: `npm run dev`

2. **После деплоя:**
   ```bash
   # Проверьте статус PM2
   pm2 status
   
   # Проверьте логи
   pm2 logs idylle-spb --lines 20
   
   # Проверьте сайт в браузере
   curl -I https://aromarussia.ru
   ```

## 🎯 Основные причины падения сайта

1. **Отсутствие сборки** (`.next` не существует)
   - Решение: `npm run build`

2. **Неустановленные зависимости** (пакеты из `package.json` не установлены)
   - Решение: `npm install`

3. **Ошибки компиляции** (TypeScript не может скомпилировать код)
   - Решение: Исправить ошибки в коде или добавить `@ts-ignore`

4. **Ошибки миграции БД** (Prisma схема не синхронизирована с БД)
   - Решение: `npx prisma db push` и `npx prisma generate`
