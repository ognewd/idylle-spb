## 🎓 Как использовать с Cursor

### Метод 1: Drag & Drop (Рекомендуется)

1. Откройте этот проект в одном окне Cursor
2. Откройте ваш проект в другом окне
3. Перетащите компоненты из `/src/app/components/` в ваш `src/components/`

### Метод 2: Cursor AI

1. Откройте Cursor Chat (`Cmd/Ctrl + L`)
2. Прикрепите файл компонента
3. Скажите: "Создай этот компонент в src/components/"

### Метод 3: Cursor Composer

1. Откройте Cursor Composer (`Cmd/Ctrl + K`)
2. Скажите: "Создай структуру компонентов из [прикрепите файлы]"

**Подробнее в:** [CURSOR_INTEGRATION_GUIDE.md](./CURSOR_INTEGRATION_GUIDE.md)

## 🎨 Кастомизация

### Быстрая замена через Cursor AI

**Изменить название магазина:**
```
Cmd/Ctrl + K → "Замени 'Aroma Boutique' на '[Ваше название]' везде"
```

**Изменить цветовую схему:**
```
Cmd/Ctrl + K → "Замени все amber оттенки на blue во всех компонентах"
```

**Добавить свои товары:**
```
Откройте HeroSection.tsx
Cmd/Ctrl + K → "Добавь 3 новых товара в массив products"
```
