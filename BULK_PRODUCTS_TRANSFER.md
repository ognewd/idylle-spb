# Массовый перенос товаров между категориями

## Функционал

Создан новый раздел админки **"Товары - Таблица"** для работы с товарами в табличном формате (как в Excel) и выполнения массовых операций.

## Где найти

`/admin/products-table` или через главную страницу админки → секция "Каталог" → карточка "Товары - Таблица"

## Возможности

### 1. Табличное представление
- Все товары в виде удобной таблицы
- Колонки: Чекбокс | Название | Бренд | Категории | Цена | Остаток | Статус

### 2. Фильтрация и поиск
- **Поиск** по названию или slug товара
- **Фильтр по категории**: все категории, без категории, или конкретная категория
- Счетчик отфильтрованных товаров

### 3. Сортировка
- Клик по заголовку колонки для сортировки
- Сортировка по: Названию, Цене, Остатку
- Порядок: по возрастанию / убыванию

### 4. Множественный выбор
- Чекбокс для выбора отдельных товаров
- Чекбокс в заголовке для выбора всех отфильтрованных товаров
- Счетчик выбранных товаров

### 5. Массовые операции

#### Изменение категории
1. Выберите товары (чекбоксы)
2. В выпадающем списке "Выберите действие" → "Изменить категорию"
3. Выберите целевую категорию
4. Нажмите "Применить"
5. Все выбранные товары будут перемещены в новую категорию (старые связи удаляются)

#### Изменение статуса активности
1. Выберите товары
2. Выберите действие "Изменить статус"
3. Выберите "Активен" или "Неактивен"
4. Нажмите "Применить"

## Решение проблемы с "Аромат для дома" и "Ароматы для дома"

### Шаги для исправления:

1. Откройте `/admin/products-table`
2. В фильтре выберите категорию "Аромат для дома" (98 товаров)
3. Нажмите чекбокс в заголовке таблицы (выбрать все 98 товаров)
4. Выберите действие "Изменить категорию"
5. Выберите категорию "Ароматы для дома"
6. Нажмите "Применить"
7. Готово! Все 98 товаров перенесены в правильную категорию

### После переноса:
- Можно удалить пустую категорию "Аромат для дома" через `/admin/categories`

## API Endpoints

### POST `/api/admin/products/bulk-update-category`
Массовое изменение категории товаров

**Body:**
```json
{
  "productIds": ["id1", "id2", "id3"],
  "categoryId": "target-category-id"
}
```

**Поведение:**
- Удаляет все существующие связи товаров с категориями
- Создает новые связи с указанной категорией
- Требует авторизацию (admin или super_admin)

### POST `/api/admin/products/bulk-update-status`
Массовое изменение статуса активности

**Body:**
```json
{
  "productIds": ["id1", "id2", "id3"],
  "isActive": true
}
```

## Безопасность

- Требуется авторизация через NextAuth
- Доступ только для пользователей с ролью `admin` или `super_admin`
- Проверка существования категории перед переносом
- Транзакционные операции для целостности данных
